ビルド方法

Node.js v18.3.0以上の環境を用意し、GitHubのprogedu/book-rendererの権限をつけてもらい、GitHubにアクセスできる環境にて、

npm install
npm run build
npm start

以上でを実行し、_forCMS フォルダにビルド生成されたHTMLを確認可能。新規で原稿を追加する際には、README.mdにリンクを書き足す必要がある。HTMLの書き方は EXAMPLE.md を確認すること。

セクションの教材種別につける大文字

種別 対応する大文字
大学動画 M
大学補助テキスト S
大学問題HTML Q
大学レポート R
大学確認テスト T
大学授業 L
大学参考書 G
単位認定試験セット EA,EB,... (Eの後にA~Zをつける)

基本的にテキストはGを利用し、大学の確認テストはTを利用する。 動画のインポートに関してはMだが、このリポジトリでは管理しないため、一旦は、GとTを利用することを知っておけば問題ない。

大学参考書は、 03A013_01_G01 のような形式となる。科目コード_2桁の回番号_G2桁のセクション番号 という形式でフォルダ名及びマークダウンファイル名を作成する。

リポジトリ名の設定

book-renderer.config.js と package.json で自分のリポジトリ名に変更する。 またフォルダ、 assets/progedu/zen-text-template も自分のリポジトリ名に変更する。

book-renderer.config.js

  repositoryName: 'progedu/zen-text-template',
  buildForNewCMS: true,
  courseType: 'zen_university',

package.json

  "name": "zen-text-template",

  "repository": {
    "type": "git",
    "url": "git@github.com:progedu/zen-text-template.git"
  },
