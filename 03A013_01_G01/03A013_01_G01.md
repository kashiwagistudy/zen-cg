## この科目で習うこと
この科目では、タイトルの通りオブジェクト指向プログラミングをScala（スカラ）というプログラミング言語で学んでいきます。

### 前提知識として必要なこと
この科目を学ぶのに必要な前提知識はなんらかのプログラミング言語によるアプリケーション開発経験です。

もっと具体的に言えば、プログラミングの三大要素となる

- 順次実行
- 分岐
- ループ

以上を何かしらのプログラミング言語で実装したことがあること、そして、

- 変数
- 論理演算
- 関数
- コレクション (配列やリストなど)

これらの概念を理解していることが望ましいです。しかし、これらに関しても再度説明はしていきますので、もう忘れてしまったよという方も安心して進めていただければと思います。。

なお学んで行く際には、Scalaのプログラミング環境を構築し、実際にコードを書きながら学んで行くため、必ずWindowsかmacOSのPCが必要となります。

### オブジェクト指向プログラミングの概要
オブジェクト指向プログラミング、と言うと一気に難しくなる気がしますが、その内容は実はとてもシンプルです。
データと振る舞いを持つオブジェクトを定義し、それらを組み合わせてアプリケーションを作っていくというものです。正確な定義づけはは実はありません。

なお、オブジェクト指向プログラミングのさまざまな技法としてデザインパターンであったり、ドメイン駆動設計といったようなアプリケーション設計の手法がありますが、現在ではこれらは言語自身やフレームワークの機能として提供されることが多くなってしまったため、そのような技法をいちいち覚えて実装しなくても良い場合があります。ただ知っておくとコードの理解が深まるというメリットはあります。

オブジェクト指向プログラミングは、1960年代中頃にアラン・ケイが提唱したものです。最初はSimulaというプログラミング言語で実装されました。その後、Smalltalkというプログラミング言語で実現されて以降、C++、Java、C#、Ruby、Python、JavaScript、PHP、Scalaなど、非常に多くのプログラミング言語で採用されています。今では、非常に多くのアプリケーション開発の現場でオブジェクト指向プログラミング言語が使われています。

先ほども言った通り、実は、オブジェクト指向に関しては正確な定義はありません。しかし、プログラミングを行なっていく中で事象をモデル化する際に、オブジェクトというデータと振る舞い(演算)を持つものを定義するというところは共通しています。

Scalaという言語では、このオブジェクトをたとえば

```scala
object Person:
  val name = "太郎"
  def sayName: Unit = println(s"私の名前は${name}です。")
```
このように書くことができます。これは、Personというオブジェクトを定義し、その垢にnameという名前のデータを所持するフィールドとsayNameという標準出力に名前をフォーマットして出力する処理を実行するメソッドを定義しています。このように定義されたオブジェクトは、Person.nameやPerson.sayNameというように呼び出すことができます。ここにおけるnameがデータ、sayNameが振る舞いというわけです。

なお、ここでは一人の人物しか表さなかったためオブジェクトで表現しましたが、それらを抽象化したクラスという概念で、Personを表現することもあります。すると名前の違う複数の人を表現できます。さらにそのクラスの特性を人だけではなく、動物だったり、生き物と暮らすごとに細分化したり、喋ることができる存在や名前を持つ存在、のような特性を持つトレイトのミックスインで複数の特性を組み合わせて新たなクラスを作るということもできます。それらの技法については、この科目のなかで学んでいきます。

なおScalaのような純粋なオブジェクト指向プログラミング言語以外のプログラミング言語では、言語の機能の中でオブジェクトではないデータであったり、オブジェクトの振る舞いではない関数などが存在する場合が多々他あります。

Javaで言うところのプリミティブ型といわれるデータ型もそうですし、特定のオブジェクトやクラスに所属しないメソッドの関数があるPythonという言語もあります。Scalaは純粋関数型言語という側面もありますが、純粋なオブジェクト指向言語という側面をもっています。そのため全てのものをオブジェクトとして扱います。こういう理由もあってScalaはオブジェクト指向プログラミングの特性を学ぶのに適した言語といえます。また静的型付け言語であり、オブジェクト指向言語のテクニックとして重要なクラスやトレイトなどの抽象データ型を利用した手法を学ぶことができるというのもその特徴の一つです。

### オブジェクト指向プログラミングの活用されるシーン

オブジェクト指向プログラミングの技法を学ぶとどのようなメリットがあるでしょうか。オブジェクト指向プログラミングの技法が使われやすいプログラミング言語に以下のようなものがあります。

- Java
- C#
- TypeScript
- Python
- Ruby

このような言語でオブジェクト指向プログラミングの技法を学ぶことで、それらの言語での開発がよりスムーズになるでしょう。この科目で習うオブジェクト指向プログラミングの特性さえ知っておけば、ああScalaにおけるこの機能のことね、とすんなりと別の言語でもコードを書いていくことができるようになるでしょう。

オブジェクト指向プログラミングは、モデルの構造化や知識の構造化に利用されるということもあり、

- ゲーム開発
- 大規模なアプリケーション開発

こういったものには欠かすことのできない技術となっています。すでにオブジェクト指向プログラミングはアプリケーション開発の現場位において必須の知識となっており、必ずやこの科目で学ぶことがアプリケーション開発をしていく上で役に立つことを保証します。

なお逆にオブジェクト指向プログラミングを使わないといったコンセプトのプログラミング言語もあります。それは手続型のプログラミング言語であるC言語やGo言語のような言語であったり、純粋関数型プログラミング言語のHaskellなどです。これらの言語では、オブジェクト指向プログラミングでストリームオブジェクトでで処理するたとえばIO処理であったり、イベントを監視するオブザーバーパターンという非同期を処理する方法などは、別な方法で実現されています。この科目ではこれらの非オブジェクト指向プログラミング言語でやっている手法をさらに深く理解するためにこれらについてはこの科目の中では扱いません。

### 最終的にこの科目を終えるとどうなるか

この科目を終えることで、最終的に皆さんには、オブジェクト指向プログラミング言語のどのようなものを扱うことになったとしても、コードを書くことができ、そのやろうとしていることが理解できるだけの実力を身につけることができるでしょう。

実際に手を動かしながら作っていきますので、皆さんも手を動かして、気になることがあればコードを改変などして、自分のものにしていってください。

## 問題1
オブジェクト指向プログラミングの由来についての記述として適切なものはどれか。

1. オブジェクト指向プログラミングは1960年代中頃にアラン・ケイが提唱し、Javaで初めて実装された
2. オブジェクト指向プログラミングはモデルの構造化に、知識の構造化にのみ利用される
3. オブジェクト指向プログラミングは1960年代中頃にアラン・ケイが提唱し、Simulaというプログラミング言語で初めて実装された
4. オブジェクト指向プログラミングはすべてのプログラミング言語で採用されている

### 正解1
3. オブジェクト指向プログラミングは1960年代中頃にアラン・ケイが提唱し、Simulaというプログラミング言語で初めて実装された

#### 解説
オブジェクト指向プログラミングは、1960年代中頃にアラン・ケイによって提唱され、初めてSimulaというプログラミング言語で実装された。その後、さまざまなプログラミング言語に取り入れられ、現在ではJavaやPythonなど多くの言語で採用されている。しかし、すべてのプログラミング言語がオブジェクト指向を採用しているわけではない。また、オブジェクト指向はモデルの構造化だけでなく、知識の構造化にも利用されるだけでなく、大規模なアプリケーション開発やゲーム開発などにも利用される。


## 問題2
この科目を終えたとき、どのような実力が身につくか適した選択肢はどれだ。

1. オブジェクト指向プログラミングを理解し、任何のオブジェクト指向プログラミング言語でもコードを書き、理解できる実力を得る
2. WindowsまたはmacOSのPCを操作する能力が身につく
3. プログラミングの三大要素となる順次実行、分岐、ループを理解できるようになる
4. オブジェクト指向プログラミングを理解し、Scalaだけでなく他のプログラミング言語でもコードを書くことができるようになる

### 正解2
1. オブジェクト指向プログラミングを理解し、任何のオブジェクト指向プログラミング言語でもコードを書き、理解できる実力を得る

#### 解説
最終的にオブジェクト指向プログラミング言語のどの言語でも、コードを書き、そのやろうとしていることが理解できるだけの実力を身につけることができるとされている。したがって、1.が正解である。

> 1. オブジェクト指向プログラミングを理解し、任何のオブジェクト指向プログラミング言語でもコードを書き、理解できる実力を得る

これが正解です。

> 2. Windows または MacOS の PC を操作する能力が身につく

これは要求条件の一つですが、この科目を終えた時に必ずしも達成されるわけではありません。

> 3. プログラミングの三大要素となる順次実行、分岐、ループを理解できるようになる

これはこの科目を始める前にすでに理解していることが望ましい前提知識です。

> 4. オブジェクト指向プログラミングを理解し、Scalaだけでなく他のプログラミング言語でもコードを書くことができるようになる

他のオブジェクト指向プログラミング言語でもコードを書くことができるようになるのが目指すところです。
